以「奶蛙 / 奶帝」这条梗线的《文明 6》新文明。**单领袖：奶帝**；奶家其他成员做成特色兵种。

## 奶帝这个梗（写在百科里）

- 《奶魂大陆》式的斗罗大陆戏仿：大陆上人人十八岁参加「奶魂觉醒」，身体随机一个部位变成奶魂形态，部位越重要实力越强；传说有人觉醒**头部奶魂**，成就至高无上的「奶帝」之位，飞升上界。
- 帝王立绘线：奶蛙戴十二旒冕冠、披黑金龙袍、捧玉玺，一登基评论区就改口叫「奶帝」。

两条线指向同一件事：**给一只只会狂笑的黄色生物，配一整套人间最高规格。** 反差就是笑点，所以特性也照这个逻辑写——觉醒 → 生产力。

## 怎么装

整个 `NaiwaCiv` 文件夹丢进：

```
C:\Users\<你的用户名>\Documents\My Games\Sid Meier's Civilization VI\Mods\
```

## 已知风险（先说清楚）

1. **这台生成机器没有游戏，没跑过 Build、没进游戏实测。** 数据表结构照社区验证过的写法：`Units` + `UnitReplaces` + `TypeTags` + `UnitAiInfos` + `UnitUpgrades`，`TraitType` 把兵种挂到文明特性上。
2. **兵种没有定义美术资源（`ArtDefine_*` / 模型）。** 常见结果是沿用被替换单位的模型；如果进游戏发现兵种是隐形的，需要在 Windows 上用 AssetEditor 补美术定义，或者先把 `UnitArtInfo` 指向现成单位。
3. **兵种图标暂时用被替换单位的原图标**（`ICON_UNIT_SCOUT` / `ICON_UNIT_WARRIOR` / `ICON_UNIT_BUILDER`），避免自造图集索引出错。要做专属图标，按领袖那套流程加 dds 即可。
4. **文明图标路径是相对路径**（`Icons/xxx.dds`）。如果游戏没认出来，图标空白不会崩溃——把 `NaiwaCiv_Icons.xml` 里的 `Filename` 改成纯文件名，dds 挪到模组根目录再试。
5. **分寸**：奶帝只用头衔 + 冕旒龙袍这个视觉母题，没有把任何真人做成游戏角色。本地自用没问题，不建议上传创意工坊。
